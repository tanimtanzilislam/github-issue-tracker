1️⃣ What is the difference between var, let, and const?
Ans:var: Function-scoped, can be redeclared and reassigned.
let: Block-scoped, can be reassigned but not redeclared.
const: Block-scoped, cannot be reassigned or redeclared.
2️⃣ What is the spread operator (...)?
Ans:The spread operator (...) expands elements of an array or properties of an object. It is used to copy, merge, or update arrays and objects.

Example:
const arr = [1, 2];
const newArr = [...arr, 3];
3️⃣ What is the difference between map(), filter(), and forEach()?
Ans:map(): Creates and returns a new array after modifying each element.
filter(): Creates and returns a new array with elements that match a condition.
forEach(): Loops through elements but does not return a new array.
4️⃣ What is an arrow function?
Ans:An arrow function is a shorter way to write a function using the => syntax.

Example:
const add = (a, b) => a + b;
5️⃣ What are template literals?
ans:Template literals use backticks ( ) to create strings. They allow string interpolation with ${} and support multi-line strings.

Example:

const name = "John";
console.log(`Hello, ${name}`);
